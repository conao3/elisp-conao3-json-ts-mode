#+title: conao3-json-ts-mode
#+author: Naoya Yamashita

A tree-sitter-based major mode for JSON files in Emacs.

* Overview

=conao3-json-ts-mode= provides syntax highlighting, indentation, and imenu support for JSON files using Emacs 29's built-in tree-sitter integration. It uses a custom tree-sitter grammar to parse JSON files.

* Requirements

- Emacs 29.1 or later (with tree-sitter support)

* Installation

** Using leaf.el

#+begin_src emacs-lisp
(leaf conao3-json-ts-mode :ensure t)
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package conao3-json-ts-mode
  :ensure t)
#+end_src

** Manual Installation

Clone this repository and add it to your =load-path=:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/conao3-json-ts-mode")
(require 'conao3-json-ts-mode)
#+end_src

* Usage

To open a JSON file with this mode, run =M-x conao3-json-ts-mode=.

To automatically use this mode for all JSON files, enable the global minor mode:

#+begin_src emacs-lisp
(conao3-json-ts-mode-mode 1)
#+end_src

The tree-sitter grammar will be installed automatically on first use if it is not already available.

* Features

- Syntax highlighting for strings, numbers, booleans, and null values
- Automatic indentation with 2-space offset
- Imenu support for navigating objects and arrays
